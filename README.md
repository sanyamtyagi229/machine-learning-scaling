Machine Learning Feature Scaling
This repository contains code and datasets demonstrating the importance and implementation of feature scaling (specifically Standardization) in machine learning workflows using Python.

📁 Repository 
FilesStandardization.ipynb: 
A Jupyter Notebook detailing the step-by-step implementation of feature scaling. It covers loading the dataset, exploring the distributions, applying StandardScaler, and observing the effects on machine learning models.
Social_Network_Ads (1).csv: The dataset used in the notebook, containing user demographic and purchase behavior data, ideal for classification and scaling demonstrations.


🚀 What is Standardization? 
Standardization is a feature scaling technique that shifts the distribution of features to have a mean of 0 and a standard deviation of 1 (Unit Variance). 

It is calculated using the formula:$$z = \frac{x - \mu}{\sigma}$$Where:$x$ is the original feature value,$\mu$ is the mean of the feature values,$\sigma$ is the standard deviation.
